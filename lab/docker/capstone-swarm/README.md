# Итоговое задание Docker Swarm: отказоустойчивая оркестрация сервиса

Лабораторная состоит из 13 последовательных шагов. Рабочий каталог студента — `/home/ubuntu/capstone-swarm`; stack называется `market`, публичная точка входа — `http://127.0.0.1:8080`.

Каждый каталог шага содержит student-facing теорию и задание, `step.yaml`, root-проверку и root-решение. Готовая реализация намеренно находится только в служебных скриптах.
